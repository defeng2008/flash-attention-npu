# MLA 场景 L1 流水设计说明

## 1. 计算公式

MLA 推理（吸收路径）的核心计算：

mm1: P = Q_nope · K_nopeᵀ + Q_rope · K_ropeᵀ
形状: (256, 576) × (128, 576)ᵀ → (256, 128)

mm2: O = P · V
形状: (256, 512) × (512, 128) → (256, 128)

- `576 = 512 NoPE + 64 RoPE`
- `mm1` 沿 576 维做 reduce，NoPE 和 RoPE 两段结果在 L0C 累加得到 P
- `mm2` 沿 512 维做 reduce，P 的 4 个 128 列块与 V 的 4 个 128 行块配对累加得到 O

---

## 2. L1 空间划分

L1 总占用 = 288K (QP) + 216K (KV) = 504K

| 区域 | 大小 | 槽数 | 槽大小 | 用途                                 |
| ---- | ---- | ---- | ------ | ------------------------------------ |
| QP   | 288K | 4    | 72K    | mm1 装 Q 段；mm2 装 P 段（分时复用） |
| KV   | 216K | 3    | 72K    | mm1 装 K 块；mm2 装 V 块（交替混装） |
| L0C  | 128K | 2    | 64K    | mmad 输出双缓冲                      |

### 2.1 QP 4 槽排布

Q 的 576 维按 288 维切两段，每槽 72K = 128×288×2B：

kL1=0 的槽: [NoPE 256][RoPE 32] ← (256+32)
kL1=1 的槽: [RoPE 32][NoPE 256] ← (32+256)

- 同一 m 块的两个 k 分段落在相邻槽（0/1 或 2/3），拼成完整 576 维
- `(256+32)` / `(32+256)` 交替保证每槽内 NoPE/RoPE 连续，loadA 的 96 维分段不跨语义边界
- 槽映射：`ka = idxMap[mIdx % 2] + kL1`，`idxMap = {0, 2}`
  - 偶 m 块 → 槽 0/1
  - 奇 m 块 → 槽 2/3

### 2.2 KV 3 槽环形

K 和 V 共用 `L1KV[3]` 和同一个 `iKV` 计数器，跨 mm1/mm2 连续递增：

iKV: 0 1 2 3 4 5 6
│ │ │ │ │ │ │
L1KV[0] ← K0 ──────────→ V1 ──────────→ K4 ...
L1KV[1] ←──── K1 ──────────→ V2 ──────────→ ...
L1KV[2] ←──────── K2 ──────────→ V3 ──────────→ ...

- K 块：128×288×2B = 72K
- V 块：256×128×2B = 64K（占一个 72K 槽有余）
- 落槽：`iKV % 3`

## 3. 同步事件

| 事件        | 方向      | 含义           |
| ----------- | --------- | -------------- |
| `MTE1_MTE2` | 计算→搬运 | 槽用完，可覆写 |
| `MTE2_MTE1` | 搬运→计算 | 槽搬完，可读   |

每个槽配一对独立事件，槽之间不互相阻塞。

- QP：`mte21QPIds[4]` / `mte12QPIds[4]`
- KV：`mte21KVIds[3]` / `mte12KVIds[3]`
- L0C：`mfixpIds[2]` / `fixpmIds[2]`

---

## 4. mm1 流水

### 4.1 循环结构

for nL1 in 0..3: # n 方向 512/128 = 4 块
for kL1 in 0..1: # k 方向 576/288 = 2 段
Get KV 槽, 搬 K 块
for mL1 in 0..mL1Loops:
Get QP 槽 ka = GetQPL1RealIdx(mIdx, kL1)
if nL1 == 0: 搬 Q（仅首次）
mmad(Q[ka], K[kb]) → L0C[kc]

### 4.2 时序

时间 → t0 t1 t2 t3 t4 t5
────────────────────────────────────────────────────
QP槽0/1 ▶Q(m0)▶ ║ █mmad n0█ █mmad n1█ █mmad n2█ █mmad n3█ →释放
QP槽2/3 ▶Q(m1)▶（与 m0 的 n0~n3 重叠）
────────────────────────────────────────────────────
KV槽 S0 ▶K0▶ ║ █mmad(K0)█ · · · · ▶K3▶
KV槽 S1 · ▶K1▶ ║ █mmad(K1)█ · · ▶K4▶
KV槽 S2 · · ▶K2▶ ║ █mmad(K2)█
────────────────────────────────────────────────────
L0C █P(m0,n0)█ █P(m0,n1)█ █P(m0,n2)█ █P(m0,n3)█

### 4.3 要点

- **Q 只在 `nL1==0` 搬一次**，4 个 n 块复用，`nL1==last` 才释放
- **Q 两组乒乓**：槽 0/1 算 m0 时，槽 2/3 搬 m1，搬运被 4 次 mmad 掩盖
- **K 三槽滚动**：1 个在算 + 1 个在搬 + 1 个缓冲
- **P 累加**：kL1=0 和 kL1=1 两段在 L0C 累加，得到完整 P 的一个 n 块
- `ka`：QP 槽号（A 矩阵 Q）；`kb`：KV 槽号（B 矩阵 K）；`kc`：L0C 槽号

## 5. mm2 流水

### 5.1 循环结构

for mL1:
for kL1: # k 方向 512/128 = 4 块
Get KV 槽, 搬 V 块
for nL1:
Get QP 槽 kb（P 复用 Q 释放的 4 槽）
mmad(V[ka], P[kb]) → L0C[kc]

### 5.2 时序

时间 → t0 t1 t2 t3 t4
──────────────────────────────────────────────
QP槽(P) ▶P0▶ ║ █mmad(P0·V0)█ █mmad(P0·V1)█ ...
QP槽(P) · ▶P1▶ ║ █mmad(P1·V0)█ ...
──────────────────────────────────────────────
KV槽(V) ▶V0▶ ║ █mmad(V0)█ · · ▶V1▶
KV槽(V) · ▶V1▶ ║ █mmad(V1)█
──────────────────────────────────────────────
L0C █O 累加█

### 5.3 要点

- **P 复用 QP 4 槽**：mm1 的 Q 释放后，P 的 4 个 128 列块按 `iQP%4` 落槽
- **V 进 KV 3 槽**：与 K 共用 `iKV` 计数器，跨 mm1/mm2 连续递增
- **O 累加**：`O = Σ P_i·V_i`，i=0~3，每块累加到 L0C
- **mm1/mm2 按 m 块串行**：mm2 的 P 搬运必须等 mm1 的 Q 释放；不同 m 块可重叠

---

## 6. mm1 → mm2 衔接

mm1: Q(4槽) × K(3槽) → P(256,512) 累加在 L0C
↓ fixp 搬出
P 写入 L1QP[4]（Q 已释放，P 复用 4 槽）
↓
mm2: P(4槽) × V(3槽) → O(256,128) 累加在 L0C

关键约束：

1. **QP 4 槽分时复用**：Q 和 P 不同时活跃，靠 `nL1==last` 的 `Set(MTE1_MTE2)` 释放
2. **KV 3 槽交替混装**：K 和 V 在时间上交错，靠 `iKV%3` 落槽
3. **L0C 双缓冲**：fixp 搬出与下一次 mmad 重叠

---

## 7. 设计要点与风险

### 7.1 必须做对

| 项         | 要求                                                     |
| ---------- | -------------------------------------------------------- |
| QP 槽映射  | `idxMap={0,2}`，同 m 块 kL1=0/1 落相邻槽，拼完整 576 维  |
| 槽内排布   | kL1=0 为 `(256+32)`，kL1=1 为 `(32+256)`，NoPE/RoPE 连续 |
| Q 搬运时机 | 仅 `nL1==0` 搬，4 个 n 块复用                            |
| Q 释放时机 | `nL1==last` 才 `Set(MTE1_MTE2)`                          |
| KV 计数器  | `iKV` 跨 mm1/mm2 连续递增，K/V 共用                      |
| L0C 累加   | kL1 两段累加得到 P；mm2 的 4 个 128 块累加得到 O         |

### 7.2 当前伪代码的问题

| 问题                           | 影响                        | 修正                           |
| ------------------------------ | --------------------------- | ------------------------------ |
| `Set(MTE2_MTE1)` 后立刻 `Wait` | 搬运与计算串行，buffer 退化 | 预取下一块提前到当前 mmad 之前 |
| mm2 里 `i.1mm == 0`            | 笔误，P 搬运分支永不进入    | 改为 `i.1m == 0`               |
| Q 槽 72K 装 128×256+128×64     | 80K > 72K，可能超容         | 确认 dtype 或切分              |
| `qpL1BufIter` 未递增           | 4 槽不轮转                  | 在 mL1 循环末尾更新            |

### 7.3 优化方向

- **搬运预取**：把 `CopyB(K_{i+1})` / `CopyA(P_{i+1})` 提前到当前块 mmad 之前，`Wait(MTE2_MTE1)` 只等当前块
- **3 槽流水**：1 个在算 + 1 个在搬 + 1 个缓冲，搬运抖动不影响计算
- **4 槽乒乓**：两组 QP 槽，一组算一组搬，搬运被 4 次 nL1 mmad 掩盖

## 8. 术语

| 符号       | 含义                                 |
| ---------- | ------------------------------------ |
| `nL1Loops` | n 方向 L1 tile 数 = 512/128 = 4      |
| `kL1Loops` | k 方向 L1 tile 数 = 576/288 = 2      |
| `mL1Loops` | m 方向 L1 tile 数 = 256/mL1SizeAlign |
| `ka`       | QP 槽号（A 矩阵 Q 或 P）             |
| `kb`       | KV 槽号（B 矩阵 K 或 V）             |
| `kc`       | L0C 槽号                             |
| `iKV`      | KV 环形计数器，跨 mm1/mm2 递增       |
| `iQP`      | QP 环形计数器                        |
| `mIdx`     | m 块逻辑编号                         |
